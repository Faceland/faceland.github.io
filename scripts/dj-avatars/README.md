# DJ room avatar anchors

The DJ room draws each avatar's eyes and hat on top of its face emoji. Every
system draws emoji differently, so `src/pages/DJ/avatarAnchors.js` stores,
per emoji font, where each face's eyes and head top are, and where, how big,
how tilted and in which layer each accessory goes. All of it is generated by
this tool from each system's real emoji art, then checked by eye.

Systems: `apple` (iOS, macOS), `google` (Android, ChromeOS, Linux),
`samsung`, `win11`, `win10` and `twemoji` (Firefox on some systems). The
site works out which one the viewer has from the platform plus the colour
layout of a few "probe" glyphs it draws (see `avatarArt.js`).

## Adding a face or accessory

1. Add it to the lists in `src/pages/DJ/avatarParts.js` **and**
   `dj-server/avatarParts.js` (the server only accepts listed emoji). It
   should exist in Emoji 12 or earlier (Windows 10's font stops there). Faces
   work best facing forward with visible eyes; ones without (🌵, 🐞, 🐌)
   just get hand-placed spots.
2. Run on **Windows 10** (its emoji come from the local Segoe UI Emoji font;
   the other systems' come from Emojipedia), from the repo root:

   ```sh
   node scripts/dj-avatars/tool.js fetch measure build sheets
   ```

   `fetch` downloads art for any emoji it doesn't have yet into
   `scripts/dj-avatars/work/` (ignored by git). `measure` prints faces where
   it found no eyes, or eyes it can't believe (ear tips, patterns).

3. Check the sheets in `work/sheets/`: `faces-<system>.png` has every face
   in glasses and a hat, and `<accessory codepoints>.png` (one per
   accessory) has it on a dozen sample faces, one row per system, to compare
   side by side. To zoom in, or check on other faces:

   ```sh
   node scripts/dj-avatars/tool.js sheets=🎩,👓 samples=🌵,🐞 em=128
   ```

4. Fix anything off in `tuning.json` and run `build sheets` again. To read
   positions off by eye,

   ```sh
   node scripts/dj-avatars/tool.js annotate=win11:🐮,apple:🎃
   ```

   draws `work/sheets/annotate.png`: each glyph's ink box with a 0.1 grid, so
   a point's grid position divided by 10 is its value.

## tuning.json

All points are fractions of a glyph's ink box (its non-transparent bounds):
x and widths of its width, y of its height.

`faces.<system>.<emoji>` replaces a face's detected anchors with
`[eyes x, eyes y, eye spacing, hat x, hat y, head width]`, plus optionally
an eye tilt and a head tilt (degrees, clockwise) for slanted faces. The eyes
point is midway between the eyes; the hat point is the top of the head
(between ears or horns, not the tip of a tuft).

`accessories.default.<emoji>` is the starting placement for every system and
`accessories.<system>.<emoji>` overrides it for one, key by key:

| Key        | Meaning                                                                                                                                                                       |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x`, `y`   | The accessory's own point that goes on the face's spot (measured: a hat's bottom middle, the midpoint between glasses' lenses, a pair's centre).                              |
| `size`     | Its width, in eye spacings (eyes) or head widths (hats).                                                                                                                      |
| `fit`      | Glasses only, instead of `size`: their lens spacing in eye spacings.                                                                                                          |
| `dx`, `dy` | Moves it, in the same units (positive `dy` sinks a hat onto the head).                                                                                                        |
| `tilt`     | Turns it, in degrees (a pair's left one turns the other way).                                                                                                                 |
| `layer`    | `front` (default), `behind` the face, or `split`: behind, with the part above its point drawn again in front (a helmet's dome over the head, its chin strap behind the face). |
