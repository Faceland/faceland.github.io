# DJ room avatar anchors

The DJ room draws each avatar's eyes and hat on top of its face emoji. Every
system draws emoji differently, so `src/pages/DJ/avatarAnchors.js` stores,
per emoji font, where each face's eyes and head top are and where each
accessory's own anchor point is. All of it is generated by this tool from
each system's real emoji art.

Systems: `apple` (iOS, macOS), `google` (Android, ChromeOS, Linux),
`samsung`, `win11`, `win10` and `twemoji` (Firefox on some systems). The
site works out which one the viewer has from the platform plus the colour
layout of a few "probe" glyphs it draws (see `avatarArt.js`).

## Adding a face or accessory

1. Add it to the lists in `src/pages/DJ/avatarParts.js` **and**
   `dj-server/avatarParts.js` (the server only accepts listed emoji). A face
   should face forward with visible eyes and a clear head top on every
   system, with no hat or glasses of its own, and exist in Emoji 12 or
   earlier (Windows 10's font stops there).
2. Run on **Windows 10** (its emoji come from the local Segoe UI Emoji font;
   the other systems' come from Emojipedia), from the repo root:

   ```sh
   node scripts/dj-avatars/tool.js fetch measure build sheets
   ```

   `fetch` downloads every listed emoji, so it takes a minute; the art lands
   in `scripts/dj-avatars/work/` (ignored by git).

3. Look at `work/sheets/<system>-faces.png` (every face in glasses and a
   hat), `-eyes.png` and `-hats.png`. The tool prints any face where it
   couldn't find eyes, and some it finds wrong (nostrils, ear insides,
   eyebrows), so check each new emoji on all six sheets.
4. Fix anything off in `overrides.json`, which beats the detected values.
   To read positions off by eye:

   ```sh
   node scripts/dj-avatars/tool.js annotate=win11:🐮,apple:🎃
   ```

   draws `work/sheets/annotate.png`: each glyph's ink box with a 0.1 grid,
   so a point's grid position divided by 10 is its value. Then run
   `build sheets` again and recheck.

Accessory sizing that's the same on every system (how wide a hat sits
relative to the head, how far down it goes, tilt, drawing it behind the
head) lives with the accessory in `avatarParts.js`.

## Formats

All values are fractions of the glyph's ink box (its non-transparent
bounds): x and widths of its width, y of its height.

- Faces: `[eyes x, eyes y, eye spacing, hat x, hat y, head width]`. The eyes
  point is midway between the eyes; the hat point is the top of the head
  (between ears or horns, not the tip of a tuft).
- Glasses (`kind: 'glasses'`): `[x, y, lens spacing]`, the point midway
  between the lenses and the distance between their centres. "Pair" eyes
  (one per eye) are centred on their ink box and need no anchors.
- Hats: `[x, y, width]`, the point that sits on the head (the bottom of the
  hat's main body) and how much of the hat's width counts as its width.

`overrides.json` holds `{ "faces": { system: { emoji: [...] } },
"accessories": { system: { emoji: [...] } } }` in the same formats.
